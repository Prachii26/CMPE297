# Decisions

One line per call I made without asking. Newest at the bottom.

- **Folder name is `assignment3`, lowercase.** The existing folders on disk are `assignment1` and `assignment2`, both lowercase, and the brief said to match that style.
- **Cloned the reference repos with `git clone` over HTTPS, not `gh`.** `gh` is not installed on this machine and installing it needed admin rights; all five repos are public, so plain `git clone --depth 1` reaches the same commits.
- **Added `*.db` to the root `.gitignore`.** The SQLite files for agents C and E are generated by a seed function on first run, so committing them would just create merge noise.
- **Screenshots are captured with Playwright+Chromium from a throwaway venv in `_reference/.shotenv`.** Keeps the browser dependency out of every agent's `requirements.txt` while still producing real screenshots of the dev UI, and `_reference/` is already gitignored.
- **Ran `adk telemetry disable` once.** The dev UI's consent modal covered the trace in the first screenshot attempt; disabling it is also the honest default for a graded assignment.
- **Agent C: unshallowed the `adk-samples` clone to read the deleted sample.** `software-bug-assistant` was removed from upstream `main` during a repo restructure, so I read it at the parent of the commit that deleted it (`fd9b4fe^`) rather than substituting a different sample.
- **Agent C: dropped the upstream vector/semantic ticket search.** It needed an embedding model and a vector store; a `LIKE` match plus real triage ranking keeps the agent dependency-free and the ranking is the part the brief asked us to change. Logged as a known limit in the agent README.
